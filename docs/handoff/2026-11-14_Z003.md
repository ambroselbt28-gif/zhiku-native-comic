# Z003 多剧情拆页与保留分镜整楼重画

## 交付

版本为 `0.8.54-native.3`，分支为 `task/Z003-comic-reroll`。
安装地址为 `https://github.com/ambroselbt28-gif/zhiku-native-comic`。

楼层下方新增「保留分镜，整楼重画（N 页）」。一次点击顺序调用已有生图接口重画所有已存页，每页换新随机种子，原分镜与正文保持原样。图片按既有版本机制追加，最多保留 10 版，失败页保留旧图并显示错误。整楼任务共享重复点击产生的请求，生成期间阻止同楼的重复重画、编辑、改编和删除。

漫画设置的自动页数改为「按剧情」。副 API 指令明确要求按独立剧情事件、场景变化和关键转折拆页，一段剧情一张图片，单条正文可以多张，每页再安排多个画格。提示词增加两段剧情、两张页面的完整示例。固定页数继续读取已存设置。

完整正文进入改编请求。识别出未闭合页面，或者最后一段只有分镜规划、缺少页面时，提示输出未完成。已有一页分镜按新规则拆页，需要选择「按剧情」后重新改编这一楼。

## 源文件与接口

- `src/comic.js` 新增 `redrawAll(id)`，返回本次总页数、成功、失败与已完成页数。`generateOne` 增加可选种子与整楼任务身份，返回是否成功，已有调用方式兼容。
- `status(id).busy` 覆盖整楼重画，按范围补图继续跳过正在生成的楼层。
- `adaptRequest` 更新多剧情拆页规则，`adapt` 使用完整的清理后正文。`parseAdapt` 检查截断输出。
- `tools/build-extension.mjs` 版本号同步，`runtime.js`、清单与包信息已重新构建。

## 人类验收步骤

1. 在手机 TT 扩展管理中更新「智库 · NAI5 原生漫画二改」，退出并重开 TT，确认关于页显示 `0.8.54-native.3`。
2. 打开智库「漫画」，将「每楼画几页」设为「按剧情」。准备包含等雨、出门、进图书馆等多个剧情片段的普通角色正文。
3. 点击该楼的「画成漫画」。已有漫画则点击「重新改编这一楼」。分镜完成后应顺序显示多张漫画页，页角标记当前页和总页数。
4. 点击漫画下方「保留分镜，整楼重画（N 页）」。应看到逐页进度，全部页各生成一张新版。
5. 点某张图片，使用上一版箭头，检查旧图仍能切回。到本页编辑窗口检查分镜内容与整楼重画前一致。
6. 如果某页失败，应在该页看到错误，已有旧图继续显示，其他页继续完成。点击该页图片后「重画这一页」可重试。

## 给下一个人的话

既有控制器入口与存储键继续兼容。`redrawAll` 使用消息、分镜、候选回复与聊天快照，切聊天、编辑正文或停用时停止后续页调度。在途结果复用既有存储校验。保留分镜重画使用当前漫画画风、颜色、尺寸与对白设置，每页单独换随机种子。
