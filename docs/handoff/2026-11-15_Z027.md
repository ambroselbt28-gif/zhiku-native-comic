# Z027 取消后续生图

版本 `0.8.60-native.26`，分支 `task/Z027-cancel-generation-queue`。用户明确要求点暂停即取消后续。

- 全局按钮改为「取消后续生图」，移除恢复入口；取消未发队列与自动重试，当前已发请求允许返回并保留成功图片。
- 使用取消轮次贯穿漫画多页、标记自身队列、正文规划、建档准备、参考图准备、批量例图与跨楼补图，防止旧流程完成异步步骤后再提交新图。之后手动生成捕获新轮次，可正常执行。
- 完成图片、旧版本与未生成的画面方案保留。取消不向远端声明撤销已经发出的请求，也不承诺退还额度。
- 保留原生图接口；内部 queueControl 删除 pause/resume，新增 cancelPending/checkpoint。其他 UI 不应再调用旧暂停接口。

验证：构建成功；63 个 Node 测试文件全部通过。源码和发布队列检查立即退队、当前成功、失败取消重试、新任务与串行保护；漫画、标记、批量及补图检查后续不再发送，文字规划取消后不生图。浏览器 390/768/1366 三档各 137 项，共 411 项通过。补图与自动建档最终增补检查另行通过。未调用付费生图接口，实际手机验收待用户更新。
