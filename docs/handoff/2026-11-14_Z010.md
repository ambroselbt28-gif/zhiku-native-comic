# Z010 漫画目录内连续生成

## 交付

版本为 `0.8.54-native.10`，分支为 `task/Z010-comic-directory`。
安装仓库为 `https://github.com/ambroselbt28-gif/zhiku-native-comic`。

用户反馈在漫画目录点击「画成漫画」后被退回聊天，再次进入时才看到正在生成，连续生成多个楼层需要反复打开阅读器。

原因是目录按钮的事件处理中显式关闭漫画书，并滚动到聊天楼层。本次让按钮直接调用既有改编流程，阅读器与目录保持打开，目录滚动位置保留。正在改编或出图的楼层显示正在生成并禁用重复点击，其他楼层可以继续选择。

## 阅读器同步

阅读器每次刷新重新读取当前已保存的漫画页，生成结果及时加入书中。单楼渲染在检查该楼是否位于聊天 DOM 前刷新阅读器，目录可以生成可视聊天范围之外的楼层。

已有页面未变化时保留阅读区域，目录复用原节点并恢复 scrollTop。有新图或版本变化时重建阅读区域，按楼层与分镜 key 找回当前页。首次生成前隐藏的翻页栏在新增图片后恢复显示。失败楼层展示错误并可在目录内重试。

`status(id)` 复用原有楼层状态计算。`render(id, { refreshBook = true } = {})` 增加可选参数，原来的单参数调用继续更新楼层及阅读器，renderAll 批量渲染时最后统一刷新书页。章节列表与书页使用当前聊天和当前候选的数据。

## 人类验收步骤

1. 在手机 TT 扩展管理更新智库二改，退出重开 TT，关于页确认 `0.8.54-native.10`。
2. 打开「漫画 → 翻看这个聊天的漫画 → 目录」。滚动到一个还没有漫画的楼层，点「画成漫画」。
3. 应保持在目录中，原楼层显示正在生成并禁用，目录停在原来的位置。
4. 直接点击另一个楼层的「画成漫画」，应可以开始下一楼。
5. 完成的楼层应自动出现封面缩略图，点击可直接阅读，阅读器无需重开。
6. 若有生成失败，目录原楼层应显示失败信息和重试入口。
