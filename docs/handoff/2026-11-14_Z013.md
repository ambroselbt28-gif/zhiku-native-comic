# Z013 人物详情长相参考分组

## 交付

版本 `0.8.60-native.13`，分支 `task/Z013-scoped-character-refs`。安装地址继续使用 `https://github.com/ambroselbt28-gif/zhiku-native-comic`。

用户确认只调整人物详情里的「长相参考」选择列表。当前卡、配角、当前聊天自动档案与人设所绑定的参考组直接显示，其他组放进默认关闭的「其他角色／未绑定的参考」。已选跨卡参考始终位于折叠外。浏览其他卡人物时按该卡归属判断，群聊包含成员卡及其配角。

未删除或迁移图片，没有新增所有权字段，不修改绑定、出图、入画选择器或角色库列表。展开后继续使用既有选择、长按管理与上传操作。

## 文件与接口

- `src/character-reference-picker.js` 提供纯分组与渲染函数。
- `tools/character-reference-picker.mjs` 将分组选择器接入正式人物页，保留当前组预览及操作。
- 构建入口、runtime、manifest、package、README、任务表更新。
- 新增分组回归，浏览器夹具使用发布代码的选择器与原有 `charrefpick` 绑定操作。

## 人类验收步骤

1. 手机 TT 扩展管理更新二改智库，退出重开，版本应为 `0.8.60-native.13`。
2. 进入「智库 → 角色 → 当前角色 → 长相参考」。本卡及当前聊天关联参考应直接显示。
3. 找到「其他角色／未绑定的参考」，默认应收起，点击可以展开并选择。
4. 选择另一张卡的参考后，该组应显示为选中且留在外面，参考图片仍正常展示。
5. 点击「不用」，应取消当前角色的参考绑定，其他角色和参考图片保留。
6. 切换聊天或查看另一张角色卡的人物，检查列表随角色归属变化。

## 给下一个人的话

参考组本身没有卡片所有权，归属由人物的 `charRef` 与当前聊天成员推导。不要按参考组名称猜归属，不要隐藏已经绑定但来自其他卡的组。未绑定组保留在折叠区供复用。此次不改变模型对角色参考的支持判断。
