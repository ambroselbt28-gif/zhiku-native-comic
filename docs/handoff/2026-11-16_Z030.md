# Z030 从画师库搜索选择组成员

版本 `0.8.60-native.29`，分支 `task/Z030-artist-library-picker`。

用户要求画师组加画师时直接搜索/选择已有画师。本次替换原「addmember」文本框入口为本地库选择弹窗：按名字、tag、备注搜索，多选跨查询保留，已有成员禁选；新成员默认权重 1、复用既有 ID，原权重与画师元数据保留。手动输入折叠入口继续解析带权重列表。

模块 `src/artist-member-picker.js` 导出筛选、加入及打开选择器。通过 `tools/artist-member-picker.mjs` 注入原 UI 模块并接正式加画师按钮。只在确认后调用原有插件配置 commit，不修改聊天。100 条分批显示；名称/备注/ID HTML 转义；对打开后被删除或替换的组阻止写入；取消不持久化。

人类验收：更新到 native.29，进入画师库并打开一个画师组，点「＋ 加画师」。输入画师名或备注关键词，勾选一位后换关键词勾选另一位，点「加入所选」。两位应加入同一个组且权重 1，原成员不重复、权重不变。再次打开可看见「已在组内」。手动添加可展开下方折叠区。取消选择后成员不变。
