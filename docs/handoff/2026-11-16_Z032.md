# Z032 生图页独立补充提示词

版本 `0.8.60-native.31`，分支 `task/Z032-studio-extra-prompts`。用户明确要求智库「生图」页生成前额外填写正面与负面提示词。

- 新增默认展开的两个文本框和「清空补充」。不改原画师串编辑、固定提示词、人物及垫图入口。
- studio 草稿保存 extraPositive / extraNegative，旧数据缺字段时为空。通过 studioParts 合入 scene / neg，复用单人和多人的发送管线及预览。
- 保存画师串仍只保存原 pos / neg；切换画师保留补充草稿；清空只影响这两个字段。仅补充正面即可生成。
- 支持英文 tag 和英文句子，中文补充会在生成时提示；自动转换仍在「固定提示词」。不宣称新字段自动翻译。

验证：构建和 runtime 语法检查；65 个 Node 测试文件（完整回归后修正新增预览断言，重跑对应文件）；390/768/1366 三档各 166 项浏览器检查。使用合成数据和模拟请求，不调用付费生图。覆盖真实生成入口的补充词单独生成与双人分人物请求、预览、草稿重载、画师保存隔离、切换保留、清空和窄屏。

人类验收：更新 native.31，打开智库→生图。在「这张图要画什么」填写正面 `1girl, reading a book`，负面 `photorealistic, 3d`，查看发送预览后点击生成。换画师串或关闭再打开，补充仍保留；点「清空补充」只清这两个框。保存画师串时不应带入这次画面内容。手机实际生图待用户验收。

给下一个人的话：本次只增加 studio 草稿字段，原对外接口不变。studioParts 的 scene 包含固定提示词和额外正面，raw pos 仍保持画师串，勿把额外内容写回画师组。
