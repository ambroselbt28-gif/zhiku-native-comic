# Z025 外貌方案快捷按钮

## 交付

版本 `0.8.60-native.24`，分支 `task/Z025-appearance-switch-buttons`。用户要求像添加衣服处一样直接切换外貌，减少弹窗操作。

## 行为与接口

- 固定外貌区直接渲染方案按钮与「＋ 保存当前外貌」，沿用 pc-pill/on/dashed 样式；通过正式 charAction 分派 applyPreset/savePreset。
- 新增 `currentAppearancePreset` 按实际英文标签及顺序匹配，忽略中文释义变化；同样内容的多个方案优先匹配 `appearancePresetId`。修改后不匹配任何方案则不高亮。
- savePreset/applyPreset 记录选择 ID，fingerprint 包含该字段以支持持久化失败回滚。重复点击当前方案直接返回，不重复保存或追加历史。
- 新增 `renderAppearancePresets`，按人物 key/id 定位，名称和属性转义，长名称换行。忙碌时禁用保存/切换。已有方案和原 AI 编辑器全部保留。
- 只切换当前外貌，不动衣服、画师或其他人物。保存及切换不请求 AI，不自动重画历史图。

## 验证

- `node dev/selftest.mjs`：63 个测试文件通过。源码及发布模块验证实际高亮、翻译不影响匹配、修改取消高亮、重复选择不写入，既有存取/回滚检查通过。
- `node dev/browser-selftest.mjs`：390、768、1366 三档各 137 项，共 411 项。使用正式按钮渲染和处理器检查快捷切换、命名保存、当前高亮、重复点击、手动修改后恢复、忙碌禁用、名称转义与手机宽度。
- 新增业务行禁写聊天模式 `/api/chats/(save|rename|delete|import|group/save|group/delete|group/import)|saveChat\s*\(|deleteMessage|deleteLastMessage|renameChat|clearChat|addOneMessage|updateChatMetadata|saveMetadata|swipe_id\s*=` 自查 0 命中。未安装依赖、未写 C/F 盘、未读真实聊天或调用付费接口。

## 人类验收步骤

1. 更新智库并等空闲自动重载，确认 `0.8.60-native.24`。
2. 角色 → 点人物 → 固定外貌，已保存的方案应直接显示为按钮。点任意方案，下面标签整套替换，当前按钮高亮并带勾。
3. 改好标签后点「＋ 保存当前外貌」，填名字，即出现新方案按钮。
4. 手动修改标签，旧方案高亮应取消；再点方案可恢复。连续点当前方案不新增历史。
5. 自然语言修改和重roll仍在「外貌方案 · 存取 / AI」。已有图片不会因切换自动变化。

## 给下一个人的话

不要只凭 appearancePresetId 判断高亮，用户可以在其他入口改标签。当前方案必须与实际标签一致。Z019 独立手机对照服务继续保留。
