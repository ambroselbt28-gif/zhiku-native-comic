# Z004 正文配图视线与互动姿势

## 交付

版本为 `0.8.54-native.4`，分支为 `task/Z004-interaction-prompts`。
安装地址为 `https://github.com/ambroselbt28-gif/zhiku-native-comic`。

默认正文插图规则明确每个人看向的对象、身体朝向、头部方向和可见手部动作。互动规则要求写清谁发起动作、谁接收、接触部位、受力姿势、人物距离和遮挡，支持动作标签的 `source#`、`target#` 与 `mutual#`。用拿手机与观察他人、递书与接书作示例。人物的注意力以剧情为依据。

画面方案增加可选英文字符串字段 `gaze_target`、`body_direction`、`head_direction`、`hands`、`interaction_role`。编译时把它们落入对应人物提示，旧方案字段继续兼容。闭眼时跳过视线对象转换，避免同一人物同时闭眼和看向物品。

正文生图的合并入口使用当前画面动态标签判断冲突类别，对画师串、聊天额外正面词、固定角色标签进行请求内过滤。明确视线时清理固定视线指令，明确朝向时清理固定朝向，明确姿势时清理固定姿势，明确手部动作时清理已知静态手臂摆拍标签。每个人单独判断，场景标签作为公共约束。固定词的权重、画师标签及其他细节通过既有分词器读取，过滤后保留其权重。

过滤后仍从原始场景和人物动作拼接请求，明确看向镜头的画面可以继续看向镜头。存档中的角色外貌、画师串和额外正面词继续由各自编辑入口管理，本次过滤在请求构建中完成。

## 人类验收步骤

1. 在手机 TT 的扩展管理更新「智库 · NAI5 原生漫画二改」，退出并重开 TT，确认关于页版本为 `0.8.54-native.4`。
2. 打开智库设置里的「正文转生图提示词」，检查出现「视线与互动姿势」规则。使用自定义提示词时，点击「恢复默认」再「保存提示词」，启用这套规则。
3. 点击「预览当前请求」，应能看到视线目标、身体朝向、手部接触和互动双方的要求。
4. 在普通正文中选一个人拿手机、另一人观察的片段生成配图。展开图片提示词，应看到前者指向手机、后者指向人物的视线描述，以及各自坐站姿势和手部动作。
5. 再用递书、扶肩或拉手等普通互动片段生成配图，检查双方动作、接触对象和站位是否符合正文。
6. 在「设置 → 问题记录」查看生图记录中的实际正面与分人物提示。明确看手机的人，其人物段应带有看手机的指令，固定外貌里的看镜头指令应已清理。

## 给下一个人的话

新增方案字段均可省略，既有接口签名继续兼容。旧默认文本的迁移采用完整匹配，修改过的文本继续由用户选择恢复默认或自行合入新规则。后续调整过滤范围时保留显式看镜头、闭眼、负权重、画师名与普通场景词的回归检查。
