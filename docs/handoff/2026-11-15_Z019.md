# Z019 手机独立 NAI 联网测试

## 交付

分支 `task/Z019-mobile-nai-test`，独立目录 `dev/nai-standalone/`。不更改扩展发布版本和运行时，也不需要手机更新插件。

用户明确要求脱离 TT，在手机进行 NAI 连接与生图对照，并确认手机和电脑处于同一 Wi-Fi。电脑 WLAN 地址为 `192.168.1.176`。已启动 `node dev/nai-standalone/server.mjs --host 192.168.1.176 --port 8766`，手机访问 `http://192.168.1.176:8766/`。更换网络后须重新确认电脑 LAN 地址。

## 机制与边界

- 电脑只提供白名单静态文件；没有 NAI 代理功能。手机浏览器使用自己的 fetch 直接连接 `https://image.novelai.net`。
- Key 是密码输入框，仅在页面内存使用；不保存、不打印、不传给电脑。页面无第三方脚本。CSP 仅允许本站脚本与官方 NAI 连接。
- 订阅 GET 最长 20 秒；生图 POST 最长 180 秒，只在用户勾选额度说明并点击后提交一次，不自动重试。运行中锁住按钮，取消只停止客户端等待，不承诺撤回服务端任务或退款。
- 两种模型可选，固定 832×1216、28 步、单图、固定种子、Euler Ancestral，无人物档案、参考图、画师串。用户可在电脑浏览器访问同页，以相同请求参数对照。
- 分别记录订阅成功、HTTP 拒绝、fetch 无可读响应、超时、取消、响应体错误和图片显示失败。HTTP 200/完整响应但解析失败不能归为网络不通；订阅成功不能代替实际生图测试。
- 支持 PNG/JPEG/ZIP 图片。未识别响应格式会明确记为图片解析失败，避免误导。无账号付费调用，真实 NAI 是否接受请求和手机网络结果待用户测试。
- 「把测试记录发给这台电脑」由用户主动点击，服务端仅接收同源 JSON，限制长度并筛选诊断字段，保存在 `.tmp/nai-standalone/report-*.json`。不上传图片或原始服务端响应。

## 验证

- `node tests/nai-standalone.mjs` 通过：官方端点、GET/POST、单次提交、两模型参数、401/403/429/500、超时、取消、错误凭据不回显、PNG 与 ZIP 解析。
- `node dev/nai-standalone/browser-test.mjs` 在 390 和 1366 宽度各 9 项通过：不自动请求、空 Key 阻止发送、生图额度勾选、GET、重复点击只发送一次、实际浏览器显示合成 PNG、错误分类、报告不含 Key、移动布局。
- 局域网页面本机 HTTP 200 校验通过。真实手机访问和付费出图尚待用户自行点击。
- 未使用 TT 上下文、插件运行时或聊天接口。新增业务行禁写聊天模式自查为 0 命中。不安装依赖，不写 C/F；使用仓库 `.tmp` 内测试缓存。测试后需停止独立服务（Ctrl+C），不自动增加系统防火墙规则。

## 人类验收步骤

1. 手机保持同一 Wi-Fi，用 Chrome 或系统浏览器打开上述地址，不在 TT 内打开。
2. 填同一个官方 Key，先点「测试连接」，再勾选额度说明并点「只生成一张测试图」。保持页面在前台。
3. 完成后点「把测试记录发给这台电脑」，或下载记录发回。
4. 电脑浏览器也打开同一地址，可用同一个 Key、同一个模型重复对照。保持两端代理选择一致。
5. 成功只能证明该时刻该浏览器请求路径可用；失败须结合 HTTP 状态、阶段和同一时段的对照判断，不能简单二分为 TT 问题或手机网络问题。
