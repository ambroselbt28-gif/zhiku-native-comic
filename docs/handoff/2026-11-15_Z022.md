# Z022 暂停生图

## 交付

版本 `0.8.60-native.21`，分支 `task/Z022-pause-image-generation`。按用户要求增加暂停与继续生图，沿用现有 GitHub 仓库发布。

## 行为与接口

- `createNaiGate` 增加 `pause/resume/snapshot/subscribe`，原 `run/stop` 接口不变。所有排队生成、冷却结束后的请求与自动重试均检查暂停；已发出的请求不强制中断。
- 计数区分 pending、active、queued。暂停中新增任务仍排队，恢复按原顺序继续。停止会唤醒暂停等待并拒绝未启动任务，不能用继续恢复已停止的队列。
- 发布模块暴露同一实例 `N.queueControl`。新增 `createGenerationPauseControls`，在面板顶部和悬浮控制条提供同一开关；后者在有任务或暂停时显示，可在漫画阅读器中操作。卸载移除监听、控件和样式。
- 暂停覆盖共用队列的官方/第三方 NAI、GPT/Comfy 生图、修图及参考编码。文字 AI 规划和只读连接测试不暂停。状态和任务不跨刷新保存。
- 没有新增聊天写入点、外部服务、依赖或付费测试。

## 验证

- `node dev/selftest.mjs`：63 个测试文件通过。新增源码与发布模块队列测试：暂停前排队、在途完成、恢复顺序、恢复立即再暂停、停止唤醒、429 冷却后重试等待。原有重试/间隔回归继续通过。
- `node dev/browser-selftest.mjs`：390、768、1366 三档各 124 项，共 372 项。新增正式控件同步、排队等待、在途暂停、恢复、空闲隐藏、手机宽度与清理检查。
- 新增业务行禁写聊天模式 `/api/chats/(save|rename|delete|import|group/save|group/delete|group/import)|saveChat\s*\(|deleteMessage|deleteLastMessage|renameChat|clearChat|addOneMessage|updateChatMetadata|saveMetadata|swipe_id\s*=` 自查 0 命中。
- 未读真实宿主数据；未安装依赖、写 C/F 盘或调用付费接口。手机真实环境待用户验收。

## 人类验收步骤

1. TT 扩展管理更新智库，空闲后关闭面板等待自动重载，确认版本 `0.8.60-native.21`。
2. 打开智库，在面板顶部点「暂停生图」。随后发起普通补图或漫画，图片请求应等待，悬浮条显示已暂停。
3. 点悬浮条「继续生图」，应正常开始生成。在多页漫画生成中再点暂停：当前已经发出的请求完成后停住，下一页等继续。
4. 进入漫画阅读器，悬浮条仍可继续或暂停。等待全部完成后悬浮条自动隐藏，面板顶部按钮保留。
5. 暂停不取消已经发出的请求，也不保存跨重启任务；实际生成仍正常消耗接口额度。
