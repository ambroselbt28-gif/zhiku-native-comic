# Z018 镜头与行动默认规则

## 交付

版本 `0.8.60-native.18`，分支 `task/Z018-camera-action-prompts`，沿用 https://github.com/ambroselbt28-gif/zhiku-native-comic 发布仓库。用户明确要求修改默认提示词与默认预设，以镜头语言设计画面并用英文句子描述行动。

## 行为

- 增加共用镜头规则：一个有剧情依据的瞬间 → 景别、机位、观看方向、裁切、层次、光源与视觉重点 → 场景关系句和每个人的行动句 → 可见性、手部、视线与动作对象校对。
- 正文自动选画面的默认 `scene_description` 要求一到两句英文，人物 `action_description` 要求一句英文，静止者描述当下姿态，不为填字段编动作。
- 手动选段/聊天生图写画面的旧 `scene` / `characters[].tags` 接口也注入同一套规则，返回字段不变。
- 镜头与临时行动不写进角色库固定外貌，人物长期特征不被本次镜头重新设计。
- 内置 AI 预设 `builtin:cinematic` 名为「镜头与行动（推荐）」，默认条目只读、可查看、可复制成自己的预设再编辑。日志和设置摘要显示正确名称。不同调用均保留自己的任务格式：翻译/读外貌不被要求额外设计镜头。
- 新配置默认使用镜头预设；已有 `active`（包括酒馆、plain 和个人预设）原样保留，额外要求和 API 选择也保留。旧用户可在 AI 预设页主动选择。
- `LEGACY_NAI_STORY_PROMPT` 保留 native.17 的完整默认文本，用于精确迁移；改过的文本不自动覆盖。角色预设与正文指令是两层，切换预设不覆盖自定义正文指令。
- 不修改网络、模型、画师、采样或角色重名解析，不自动重画旧图片，不读取真实宿主数据。

## 人类验收步骤

1. 在手机 TT 扩展管理更新现有智库，关闭智库面板与阅读器，等待空闲自动重载。确认版本 `0.8.60-native.18`。
2. 打开「智库 → 设置 → AI 预设 → 打开 AI 预设」，选择「镜头与行动（推荐）」。旧的「我的预设 1」保留，可以随时切回。
3. 如正文提示词曾自行修改，打开「正文转生图提示词」，先保存自己的文本，再点「恢复默认」和「保存」。未改过的默认会自动升级，无需操作。
4. 生成一次正常正文插图或选段生图，展开提示词：应有景别与机位，场景段包含英文关系句，各人物段描述各自当下行动。实际出图会正常消耗生图额度。
5. 在 AI 预设页点击「复制一份改」，确认副本名称为「镜头与行动 · 副本」，可以编辑，而内置版本保持原样。

## 给下一个人的话

默认预设是可选择的任务辅助层，不能暗中覆盖用户自己写的提示词。继续保留 native.17 文本做精确迁移；不要直接修改旧常量导致旧配置无法匹配。实际生图仍受模型、外貌档案、画师和提示词遵循影响。
