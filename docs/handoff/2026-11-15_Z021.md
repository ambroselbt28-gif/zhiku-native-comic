# Z021 补本楼普通生图

## 交付

版本 `0.8.60-native.20`，分支 `task/Z021-floor-illustration-backfill`。用户要求将楼层标记生图按钮改为「补本楼普通生图」。沿用现有 GitHub 安装仓库发布。

## 行为与接口

- `.pc-mes-gen` 保留原位置与图标，标题和无障碍名称改为「补本楼普通生图」。处理器从直接调用 marker.process 改为 backfill.fillFloor，显示开始、忙碌、完成/跳过/失败提示并防止重复点击。
- `createImageBackfill` 新增 `fillFloor(id)`，只调度该楼普通插图。无标记时复用 planner.backfill 调正文插图副 API，已有标记时只处理 missing 索引。
- 单楼模式允许在已有部分普通图时补剩余图。结果仍有缺图则明确失败及剩余张数，不以先前成功图片冒充本次成功。
- 批量范围补图原有「该类型已有图则跳过」行为保持不变；只有单楼补缺开启 fillMissing。正在运行另一补图任务时明确报忙，不悄悄返回别的楼层结果。同一单楼任务共享 Promise。
- 全局 gateway 扩展为 `{...backfillUI,fillFloor}`，原 open 与清理行为保留。图片保存、正文提示词准备、聊天切换和候选回复隔离继续复用原有控制器，没有增加新的宿主写入点。
- 普通插图与漫画仍各自判断；未改「画成漫画」按钮。不更新画师、模型、采样参数或固定外貌。

## 验证

- 构建成功，`node dev/selftest.mjs` 62/62 个测试文件通过；源码和发布模块合成验证覆盖关闭自动插图时单楼补图、其他楼不变、已有完整图不重画、部分成功时只补缺、部分失败不能假报成功、缺方案调用 AI、有方案不调用 AI、重复点击与跨楼忙碌保护。
- 正式浏览器在 390、768、1366 三档各 116 项通过，共 348 项。新增真实按钮注入、当前楼编号分派、重复点击与忙碌显示、成功恢复、失败可重试、跳过原因。
- 未进行付费 AI/生图调用，未读真实宿主数据，未安装依赖或写 C/F 盘；测试使用既有 `.tmp` 缓存。
- 新增业务行禁写聊天模式 `/api/chats/(save|rename|delete|import|group/save|group/delete|group/import)|saveChat\s*\(|deleteMessage|deleteLastMessage|renameChat|clearChat|addOneMessage|updateChatMetadata|saveMetadata|swipe_id\s*=` 自查为 0 命中。

## 人类验收步骤

1. TT 扩展管理更新二改智库，关闭面板等空闲重载，确认 `0.8.60-native.20`。
2. 在一条没有普通图的角色回复楼层，点原先的图片按钮（现在叫「补本楼普通生图」）。应提示开始补本楼，没有提示词时先等正文插图 AI 选画面，再生成普通图。
3. 在同楼一张成功、一张失败时再次点击，只应补失败那张。全部已有普通图时应提示已有普通插图，不消耗额外生图额度。
4. 只有漫画的楼层点此按钮仍补普通图；要画漫画继续点书本按钮。
5. 如补图失败，应显示具体原因，处理后再次点击可复用提示词重试。缺方案会消耗文字 API 额度，实际生图正常消耗图片额度。
